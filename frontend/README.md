# Super Seven Sports Academy website (Vite + React)

```
npm install
npm run dev       # local dev server
npm run build     # production build in dist/
npm run preview   # preview the build
```

- Edit all text, fees, coaches, timings in `src/data.js`.
- Logo and founder photo are in `src/assets/`.
- Items marked `[Add ...]` are placeholders to replace before going public.
- GitHub Pages: build, then publish the `dist/` folder (vite.config.js uses `base: './'`).
- Admin panel is not included (needs a backend, e.g. Supabase or Firebase).
