# Image sources used by the demo

The seeded content uses remote image URLs rather than bundling third-party images into the ZIP.

- Academy-related image reference found in the research: LyfSkills image URL used for the hero/gallery seed.
- Generic martial-arts imagery: Unsplash image URLs in `server/seed/seed.js`.

**Commercial-use warning:** verify ownership/licensing before publishing. The production site should ideally use photos supplied by Super Seven Karate Institute or properly licensed stock media. The request to use “all images present online” cannot be fulfilled safely or exhaustively because online images have different owners and usage rights.
